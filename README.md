# 🏈 Touchdown — SwiftUI E-Commerce App

A modern sports e-commerce iOS application built with **SwiftUI**, featuring a clean user interface, reusable components, and a structured approach to managing application state.

Touchdown provides a shopping experience where users can explore sports products, browse categories and brands, and view individual product details.

## ✨ Features

- **Modern UI:** Clean and visually appealing interface built entirely with SwiftUI.
- **Product Catalog:** Browse a collection of sports products.
- **Product Categories:** Explore products through organized categories.
- **Featured Products:** Highlight selected products in an interactive featured section.
- **Product Details:** View individual product information.
- **Brand Collection:** Browse products by brand.
- **Reusable Components:** Modular SwiftUI views for maintainable and reusable code.
- **State Management:** Reactive state management using SwiftUI and the Observation framework.
- **Smooth Animations:** Animated transitions between the home screen and product details.

## 🏗️ Project Architecture

The project follows a modular, component-based structure to keep the code organized and maintainable.

```text
Touchdown/
│

│   ├── FeaturedTabView.swift

│   ├── ProductItemView.swift

│   └── FooterView.swift
│
├── Resources/

│   └── Data/
│
└── Persistence/
```

## 🧠 Key Concepts Learned

Throughout the development of Touchdown, I explored and practiced several important SwiftUI concepts:

- Building responsive layouts using `VStack`, `HStack`, and `ZStack`.
- Creating dynamic product grids using `LazyVGrid` and `ForEach`.
- Managing application state using `@State`.
- Sharing observable data across views using `@Observable` and `@Environment`.
- Creating reusable and modular SwiftUI components.
- Implementing custom navigation and product selection.
- Applying animations using `withAnimation`.
- Working with custom views and SwiftUI modifiers.

## 🚀 Getting Started

### Requirements

- macOS with Xcode installed.
- Basic knowledge of Swift and SwiftUI.
- An iOS Simulator or a compatible iPhone.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd Touchdown
   ```

3. Open the project in Xcode:

   ```bash
   open Touchdown.xcodeproj
   ```

4. Select an iOS Simulator or your connected device.

5. Build and run the application using `Cmd + R`.
